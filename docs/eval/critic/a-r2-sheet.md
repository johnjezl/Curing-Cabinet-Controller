# Behavior sheet

Convention: "nominal / median / worst" means the nominal simulated plant, then the median and worst of 36 simulated plants. All running behavior is from a simulated plant; no hardware run exists. Steady-state figures come from one 24 h window (hour 18 to hour 42) and exclude defrost plus the following 40 min, unless stated.
